# magic-piano

Автоматический плеер для игр с раскладкой Virtual Piano (Roblox Magic Piano,
virtualpiano.net и клоны). Читает `.song` или `.mid` и отправляет нажатия
**только в окно игры** через IPC Hyprland, не трогая остальную систему.

Проверено в Sober на Hyprland/Wayland: гамма, аккорды и MIDI играют
правильно; фокус при этом остаётся там, где был.

## Что уже работает

- **Ввод только в окно игры**: клавиши уходят в Sober через
  `send_key_state` Hyprland. Другие окна не получают ничего, фокус не
  переключается. Режим `--global` (uinput) остался как запасной.
- **Точный Shift для аккордов**: модификатор применяется к одному событию,
  поэтому чёрная нота не «портит» соседнюю белую.
- Без сторонних Python-пакетов.
- Раскладка «белая клавиша = символ, чёрная = Shift + символ слева».
- Песни в текстовом формате и **MIDI** (форматы 0/1): tempo map, running
  status, note-on с velocity 0, несколько дорожек.
- **Аранжировка под 5 октав**: приоритет мелодии при выборе октавы, перенос
  далёких нот на октаву вместо потери, разрешение конфликтов клавиш,
  сохранение повторов нот.
- **Аккорды**: одновременные ноты, удержание, счётчик Shift, безопасный
  порядок белых и чёрных клавиш.
- CLI с сухим прогоном и точным планировщиком (~1 мс).

## Требования

- Linux + Hyprland (для адресной доставки клавиш через IPC);
- Python 3.10+, без сторонних пакетов;
- активная раскладка US (проверить: `hyprctl devices | grep 'active keymap'`);
- только для `--global`: доступ на запись в `/dev/uinput` (проще всего
  через ACL для своего пользователя).

## Быстрый старт

```bash
git clone <этот репозиторий> magic-piano && cd magic-piano

./magic-piano                                          # интерактивный интерфейс
python3 -m magic_piano.play --list-layout              # нота -> клавиша
python3 -m magic_piano.play --list-windows             # окна для --window
python3 -m magic_piano.play "songs/Classical - Debussy - Clair de Lune.mid"
```

## Интерфейс

```bash
python3 -m magic_piano
```

Полноэкранный список песен: название, длительность и число нот, поиск,
категории, выбор окна и прогресс воспроизведения. Игра запускается в фоне,
терминал при этом остаётся отзывчивым: можно остановить песню или выбрать
следующую.

| клавиши | действие |
|---------|----------|
| `Up`/`Down`, `j`/`k` | переход по списку |
| `PgUp`/`PgDn`, `g`/`G` | страница, начало, конец |
| `Enter`, `Space` | играть / остановить |
| `s` | остановить |
| `+` / `-` | скорость 0.25–3.00 |
| `t` / `T` | транспонировать на полутон |
| `0` | сбросить скорость и транспонирование |
| `/` | поиск по названию (`Enter` — применить, `Esc` — очистить) |
| `c` | следующая категория |
| `w` | выбрать окно из списка |
| `u` | адресный ввод / системный uinput |
| `r` | перечитать папку `songs/` |
| `?` | справка |
| `q` | выход (с остановкой игры) |

Опции: `--songs DIR` — другая папка, `--window SELECTOR` — стартовое окно,
`--global` — сразу системный ввод (там перед стартом будет отсчёт 3 с,
чтобы успеть переключиться в игру). Отдельного графического окна нет:
интерфейс работает в любом терминале и не требует сторонних пакетов.

## Коллекция

В `songs/` лежит 100 пьес (классика, саундтреки игр и кино) плюс
`Attack on Titan - Jiyuu no Tsubasa.mid`. Полный список с длительностью —
[`songs/COLLECTION.md`](songs/COLLECTION.md).

Сами `.mid` не коммитятся (`.gitignore`). Если их нужно восстановить или
собрать заново:

```bash
python3 tools/fetch_collection.py --report   # что будет выбрано
python3 tools/fetch_collection.py --write    # скачать и разложить в songs/
```

Скрипт берёт архив ADL Piano MIDI dataset
(<https://github.com/lucasnfe/adl-piano-midi>), проверяет каждый файл
парсером проекта и пишет манифест. MIDI-аранжировки принадлежат их авторам;
файлы предназначены для личного использования.

Свой файл: положи `.mid` в `songs/` и запусти

```bash
python3 -m magic_piano.play "songs/Мой файл.mid" --info
python3 -m magic_piano.play "songs/Мой файл.mid" --dry-run
python3 -m magic_piano.play "songs/Мой файл.mid"
```

Опции: `--bpm`, `--gate`, `--speed`, `--transpose <полутона>`, `--no-fit`,
`--tracks 1,2`, `--drums`, `--start-note C2`, `--countdown 5`.

Ввод: `--window class:org.vinegarhq.Sober` (по умолчанию),
`--window title:Sober`, `--window address:0x...`, `--list-windows`.
`--global` — старый режим через uinput на всю систему; там есть отсчёт 3 с
и защита, которая останавливает игру при смене фокуса (`--no-guard` её
отключает).

`--info` показывает дорожки: сколько нот, диапазон и длительность. По этому
видно, какую дорожку брать через `--tracks`.

## Ввод только в Roblox

По умолчанию плеер находит окно Sober (`class:org.vinegarhq.Sober`) и шлёт
каждую клавишу в него через Hyprland:

```lua
hl.dsp.send_key_state({ mods = "SHIFT", key = "q", state = "down", window = w })
```

Что это даёт:

- можно переключать окна, отвечать в терминале и браузере — ни один символ
  туда не попадёт;
- фокус не меняется, игра не сворачивается;
- Shift применяется к конкретному нажатию, так что смешанные аккорды
  (`C` + `D#`) звучат правильно;
- окно запоминается по адресу, а не только по классу: два окна Sober не
  перепутаются;
- если окно закрыть, клавиши просто перестают доставляться.

Если окно не найдено, плеер не начинает играть: проверь `--list-windows` и
передай точный селектор через `--window`. Для других сайтов/игр — тоже
`--window class:firefox` и т.п. `--global` нужен только если Hyprland нет.

## Формат песни

```
bpm 100
1 1 5 5 6 6 5     // один токен = один бит
4 4 3 3 2 2 1
```

Токен — клавиша Virtual Piano (`1`, `q`, `Q`, `!`) или нота (`C4`, `D#4`).
Аккорд — в квадратных скобках: `[1 3 5]`. `|` и `//`-комментарии
игнорируются. Комментарии именно `//`, потому что `#`
входит в имена диезов.

## Раскладка

Первая белая клавиша по умолчанию — C2 (MIDI 36): это первая клавиша,
которая вообще нажимается с клавиатуры в Roblox Magic Piano. Белые клавиши
идут по строке `1234567890qwertyuiopasdfghjklzxcvbnm`, чёрная — Shift плюс
белая клавиша слева.

```
C2=1  C#2=Shift+1  D2=2  D#2=Shift+2  E2=3  F2=4  F#2=Shift+4  G2=5 ...
C3=8  C#3=Shift+8  D3=9  D#3=Shift+9  E3=0  F3=q  F#3=Q  G3=w ...
C4=t  C#4=Shift+T  D4=y  D#4=Y  E4=u  F4=i  F#4=I  G4=o ...
C7=m
```

Итого 61 клавиша C2–C7 — ровно то, что игра принимает с клавиатуры.
Крайние клавиши её 88-клавишного пианино нажимаются только мышью и
повторяют те же подписи, поэтому в диапазон не входят. Проверить
соответствие: `python3 -m magic_piano.play --list-layout`.

## Если звучит не так

1. Включи в игре **Sustain** — ноты будут тянуться, звук станет полнее.
2. Дай полный диапазон: `--transpose ±12` или кнопка Transpose в игре.
3. В `--global` Shift может «покрасить» соседнюю белую клавишу: по
   умолчанию плеер на миг отпускает Shift перед белой нотой. Отключается
   через `--no-shift-pause`. В адресном режиме это не нужно.
4. Слишком быстро — `--speed 0.9`; слишком рвано — `--gate 1.0`.

## Аккорды

Ноты с одинаковым временем уходят одним пакетом, поэтому аккорд звучит
вместе, а не «арпеджио». `q` и `Q` — разные ноты, но одна физическая
клавиша: если в MIDI они пересекаются, аранжировщик оставляет мелодию,
а вторую ноту убирает (в сводке это `key conflicts`).
