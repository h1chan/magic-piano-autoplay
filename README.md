# magic-piano

Автоматический плеер для игр с раскладкой Virtual Piano (Roblox Magic Piano,
virtualpiano.net и клоны). Читает простой текстовый файл песни и отправляет
нажатия клавиш в активное окно через `/dev/uinput`.

## Что уже работает

- Виртуальная клавиатура через uinput: работает на Wayland/Hyprland и в
  Sober, где `xdotool` неприменим.
- Раскладка «белая клавиша = символ, чёрная = Shift + символ слева».
- Текстовый формат песен (`songs/*.song`) и CLI.
- Сухой прогон с таймлайном и юнит-тесты.

Пока это **мелодия**, без аккордов и MIDI. Это следующий слайс.

## Требования

- Linux с доступом на запись в `/dev/uinput` (у h1chan он уже есть через ACL);
- Python 3.10+ без сторонних пакетов;
- активная раскладка US (проверить: `hyprctl devices | grep 'active keymap'`).

## Запуск

```bash
cd ~/Projects/magic-piano

python3 -m magic_piano.play --list-layout      # таблица нота -> клавиша
python3 -m magic_piano.play songs/scale.song --dry-run
python3 -m magic_piano.play songs/scale.song   # 3 секунды на фокус в игре
```

Опции: `--bpm`, `--gate` (длина ноты в долях бита), `--start-note C3`,
`--countdown 5`.

## Формат песни

```
bpm 100
1 1 5 5 6 6 5     # один токен = один бит
4 4 3 3 2 2 1
```

Токен — клавиша Virtual Piano (`1`, `q`, `Q`, `!`) или нота (`C4`, `D#4`).
`|` и `//`-комментарии игнорируются.

## Раскладка

Первая белая клавиша по умолчанию — C3 (MIDI 48). Белые клавиши идут по
строке `1234567890qwertyuiopasdfghjklzxcvbnm`, чёрная клавиша — Shift плюс
белая клавиша слева.

```
C3=1  C#3=!  D3=2  D#3=@  E3=3  F3=4  F#3=$  G3=5  G#3=%  A3=6  A#3=^  B3=7
C4=8  C#4=*  D4=9  D#4=(  E4=0  F4=q  F#4=Q  G4=w  G#4=W  A4=e  A#4=E  B4=r
```

Если игра использует другую привязку, правится только `magic_piano/layout.py`.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

## Дорожная карта

1. Проверить звучание `scale.song` и `twinkle.song` в игре.
2. MIDI-парсер (формат 0/1, tempo map) и импорт `.mid`.
3. Аккорды и педаль: удержание нескольких клавиш, `Sustain`.
4. Автоподбор октавы/транспонирование под диапазон игры.
5. Определение своей раскладки калибратором (на случай нестандартной игры).

## Оговорка

Автоматизация нарушает правила Roblox и конкретной игры; аккаунт может быть
заблокирован. Пользуйся на свой риск и не мешай другим игрокам.
